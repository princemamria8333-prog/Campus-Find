# CampusFind AI

## About the Project
CampusFind AI is an intelligent campus Lost and Found
system that helps students recover their missing belongings.

## Problem Statement
Students frequently lose items such as ID cards,
wallets, earphones, books and chargers on campus.
Finding these items is difficult without a centralized system.

## Our Solution
CampusFind AI uses a local AI model to analyze lost
and found item descriptions and identify possible matches.

## Main Features
- Report Lost Items
- Report Found Items
- AI-Based Item Matching
- Match Explanation
- Search and Filter
- Item Recovery Requests
